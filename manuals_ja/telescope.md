# Telescope.nvim の使い方

Telescope.nvim は、ファイル検索や文字列検索、バッファや Git ファイルの管理を素早く行うための強力なプラグインです。以下に、設定されたショートカットキーや便利な機能をまとめます。

## 基本操作

### `<C-p>` でファイル検索
現在のプロジェクト内で、`.git`ディレクトリを除いたファイルを検索します。隠しファイルも含めて検索されます。

### `<C-g>` で文字列検索
プロジェクト内で、`ripgrep`を使って特定の文字列を検索します。

### `<leader>b` でバッファの一覧表示
開いているバッファの一覧を表示し、選択して移動できます。

### `<leader>fh` でヘルプタグを検索
Neovim のヘルプドキュメント内のタグを検索して、すぐにドキュメントを表示します。

### `<space>fb` でファイルブラウザを表示
ファイルブラウザを開いて、ディレクトリをナビゲートしながらファイルを開けます。

### `<leader>fr` で最近使用したファイルを検索
`frecency`プラグインを使って、最近開いたファイルを頻度順に検索します。

## 追加機能

### `<leader>fw` でカーソル下の単語を検索
カーソル位置にある単語をプロジェクト内で検索できます。

### `<leader>fo` で最近開いたファイルを検索
最近開いたファイルのリストから検索して開くことができます。

### `<leader>fg` で Git ファイルを検索
Git リポジトリ内のファイルを素早く検索できます。Git 管理されているプロジェクトでのみ機能します。

### `<leader>fp` でプロジェクトブラウザを表示
`telescope-project`プラグインを使って、プロジェクトをツリー形式でブラウズできます。

### `<leader>fq` で Quickfix リストを表示
Quickfix リストを表示し、そこからエラーや警告にジャンプできます。

---

## 注意点
- `frecency` 機能を使用するには `sqlite.lua` プラグインが必要です。
- プロジェクトブラウザには `telescope-project.nvim` プラグインが必要です。

これらの設定により、Telescopeをより効率的に使用でき、作業スピードを大幅に向上させることができます。
